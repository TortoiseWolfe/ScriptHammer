Install & first run

One command scaffolds the project, applies the Supabase schema and runs the full test suite. If it goes green you have auth, payments, messaging and offline working locally before you write a line.

npm pnpm docker
$ npx create-scripthammer my-app $ cd my-app && cp .env.example .env.local $ npm run dev → ready in 41s · localhost:3000

What you need first

Node 20 LTS
Supabase Free tier
Disk 1.2 GB
