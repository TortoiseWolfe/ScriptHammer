Spec Kit: words before code.

    
Spec Kit is a set of fill-in forms and seven steps. You describe the feature in plain words, it asks you the questions you skipped, and only then does it plan and write code.

    
specifyclarifyplanchecklisttasksanalyzeimplement

    

    
A dry run: it names the feature branch and creates nothing.
