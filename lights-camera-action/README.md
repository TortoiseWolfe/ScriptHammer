# ScriptHammer: Lights, Camera, Action

A kids' music game built with the robot band ScriptHammer: kids run a
concert from the soundboard at Ross's Landing, Chattanooga — a SOUND board
(rearrange each instrument's part), a LIGHT board (the sun and stage
effects), and a CAMERA board (zoom) — built for the Base44 × Nitro Web
Game Contest.

**Play it:** https://scripthammer-stage-play.base44.app
**Contest:** submissions close Dec 3, 2026 · winners Dec 10, 2026

## What lives here

This folder, inside the ScriptHammer repo, is the project's paper home —
everything about the game rides along here. The game's source code is
exported from Base44 to GitHub after the contest (December), per the
export plan in the business plan, and will be linked from here.

- `docs/` — business-plan.md (ownership, export plan, team, costs),
  contest-brief.md, prompt-plan.md, feedback-log.md (every build note and
  ruling, in order), album-brief.md (the release album), kit-brief.md
- `prompts/` — the exact prompt texts used to build the game, in the order
  they were fired (prompt-1-build, prompt-a-corrections), plus the
  scrapped first build's prompt, kept for provenance
- `meeting-notes/` — agenda and notes from the team meetings
- `refs/` — the reference images: the real Ross's Landing stage photos and
  the band's character sheets *(landing via a separate push — binary files
  travel a different route than the text snapshot)*
